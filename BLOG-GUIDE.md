# How to publish a blog post

1. In GitHub open the `posts` folder and click **Add file > Create new file**.
2. Name the file `my-new-article.html`.
3. Copy an existing article HTML file as a template, then replace its title and article content.
4. Commit the file.
5. Add a card linking to `posts/my-new-article.html` in `blog.html`. Optionally add it to the homepage in `index.html`.
6. Commit again and wait for GitHub Pages to deploy.

**Important:** Use `../style.css` and `../script.js` for pages inside `posts/`.

You can also edit an existing article with GitHub's pencil icon and commit your changes.
